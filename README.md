# RCD — Raveline Crew Dashboard

Production-focused Next.js 14 scaffold for an internal festival operations platform.

## Stack
- Next.js App Router + TypeScript
- TailwindCSS
- Framer Motion (subtle transitions/animations)
- NextAuth scaffold
- Prisma + PostgreSQL schema scaffold

## Routes
- `/dashboard`
- `/raveups`
- `/friendscamps`
- `/calendar`
- `/todo`
- `/drive`
- `/auth/login`
- `/auth/register`

## Run
```bash
npm install
npm run dev
```
